# 휴대폰 입금 알림 연결 안내

납부일에 월세가 들어왔는지 **바로** 확인하는 방법입니다. 사업자등록·공동인증서가 없어도 됩니다.
은행이 휴대폰으로 보내는 입금 알림을, 휴대폰 자동화 앱이 ROOMAX 전용 주소로 넘겨줍니다.

```
세입자 입금 → 은행 앱 알림/문자 → 휴대폰 자동화 앱 → ROOMAX 비밀 주소 → 장부 반영 → 홈 '오늘 납부일'
```

> 메뉴 이름·요금은 은행과 앱 버전마다 바뀝니다. 아래는 공통 순서이고, 찾기 어려우면 은행 고객센터에
> "입출금 알림 신청"을 문의하세요.

## 0. 연결 주소 만들기 (ROOMAX)

1. 설정 → **입금 알림 자동 연결** → 계좌 선택 → **연결 주소 만들기**
2. 나온 주소를 복사합니다. **한 번만** 보여 줍니다. 잃어버리면 새로 만들면 되고, 예전 주소는 바로 끊깁니다.
3. 이 주소를 아는 사람은 알림을 넣을 수 있으니 다른 사람에게 보내지 마세요.

## 1. 은행에서 입금 알림 켜기

| 할 일 | 설명 |
|---|---|
| 은행 앱 설치·로그인 | 월세 받는 통장의 은행 앱 |
| 입금 알림 켜기 | 앱의 **설정 → 알림**에서 그 계좌의 입금(입출금) 알림을 켭니다. 메뉴 이름은 은행마다 '알림 설정'·'입출금 알림'·'금융알림' 등으로 다릅니다 |
| 금액 표시 켜기 | 개인정보 보호 설정으로 금액을 숨기면("새 알림이 있습니다") 읽을 수 없습니다 |
| 알림 기준 금액 | '얼마 이상만 알림'이 있으면 가장 작은 월세보다 낮게 |
| 휴대폰 알림 허용 | 휴대폰 설정 → 앱 → 은행 앱 → 알림 허용. 방해금지·절전 모드에서 은행 앱 예외 |
| 아이폰이면 문자 알림 | 아이폰 자동화는 문자만 읽을 수 있어 **입출금 문자(SMS) 알림**을 신청 (앱·인터넷뱅킹·고객센터·영업점) |

- 앱 **푸시 알림은 대개 무료**, **문자 알림은 은행·고객 등급에 따라 월 이용료**가 있습니다 — 신청 전에 은행 안내로 확인하세요.
- 은행 고객센터: KB국민 1588-9999 · 신한 1577-8000 · 우리 1588-5000 · 하나 1588-1111 · NH농협 1588-2100 ·
  IBK기업 1566-2566 · 카카오뱅크 1599-3333 · 토스뱅크 1661-7654 · 케이뱅크 1522-1000

## 2-A. 안드로이드 — MacroDroid (무료)

1. Play 스토어에서 MacroDroid 설치 → 처음 실행 때 **알림 접근 권한** 허용
2. 매크로 추가
   - 트리거: **알림 수신** → 은행 앱 선택 (문자로 받으면 **SMS 수신** → 은행 번호)
   - 제약(선택): 알림 내용에 '입금' 포함
   - 동작: **HTTP 요청** · POST · 복사한 주소 · 본문 형식 `application/json`
   - 본문: `{"text": "[notification_title] [notification]"}` (문자면 `[sms_message]`)
     — 매직 텍스트 이름은 앱 버전에 따라 다를 수 있으니 목록에서 '알림 내용'을 고르세요
3. 휴대폰 설정 → 배터리 최적화에서 **MacroDroid 제외** (꺼 두면 알림을 놓칩니다)

## 2-B. 아이폰 — 단축어 (문자 알림만)

아이폰은 다른 앱의 푸시 알림을 읽을 수 없어 1단계의 **은행 문자 알림**이 필요합니다.

1. 단축어 앱 → 자동화 → 새 자동화 → **메시지**
   - 보낸 사람: 은행 문자 번호 · 메시지에 '입금' 포함 · **즉시 실행**
2. 동작: **URL 콘텐츠 가져오기** · 복사한 주소 · 방법 POST · 요청 본문 JSON · 키 `text` = 단축어 입력(메시지 내용)

## 3. 시험

1. 다른 계좌에서 이 통장으로 소액(예: 1,000원)을 보냅니다.
2. 몇 초 안에 설정 화면 **최근 받은 알림**에 '거래로 넣음'이 보이면 연결 완료.
   수납 화면에는 검토 대기로 들어오니 '기타'로 확정하세요.
3. '읽지 못함'이면 그 문장을 **알림 문장 시험**에 붙여 넣어 확인하고, 이름·금액을 바꿔 알려 주시면 형식을 추가합니다.
4. 아무것도 안 오면: 은행 알림이 휴대폰에 뜨는지 → 자동화 앱 실행 기록 → 주소를 새로 복사했는지 순서로 확인합니다.

## 알아 둘 것

- **알림은 '들어왔다'의 증거일 뿐**입니다. 휴대폰이 꺼졌거나 절전 중이면 알림이 빠질 수 있으므로,
  알림이 없다고 미납으로 보지 않습니다. 미납 판단·월 결산·미납 안내는 지금처럼 **통장 내역 파일** 기준입니다.
- 자동 확정 규칙은 같습니다: 입금자 이름(또는 기억한 별칭)이 계약 1건에만 맞고 금액이 가장 오래된 미납 잔액과
  같을 때만. 나머지는 검토 대기.
- 월말에 통장 내역 파일을 올리면 알림으로 먼저 들어온 거래와 **자동으로 합쳐집니다** (중복 없음, 확정 유지).
  짝이 없는 알림 거래가 있으면 경고합니다.
- 출금 알림은 무시합니다 (지출은 통장 내역 파일로).
